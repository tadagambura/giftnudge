# GiftNudge

> **Merged into [Daymark](https://github.com/tadagambura/daymark).**

Birthdays are just countdowns to people, so GiftNudge's features (people list, birthdays and
anniversaries, gift-idea notes, budgets, reminders, Christmas lists) now live in Daymark's
"people & birthdays" mode. One app instead of two near-identical ones.

This repo is kept for history and is no longer developed.
